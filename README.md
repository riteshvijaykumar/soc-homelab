## 📖 About This Project

This repository documents my journey of building a personal **Security Operations Center (SOC) Home Lab** from scratch using industry-standard open-source tools.

The primary goal of this project is to gain practical, hands-on experience in SOC operations by simulating real-world attack scenarios, monitoring endpoints, generating security alerts, and investigating incidents through a centralized SIEM platform.

Rather than simply following tutorials, I built this lab to understand how security analysts detect threats, analyze logs, and respond to security events in an enterprise environment.

![Download Sysmon](/images/Dashboard/Dashboard.png)

## 🎯 Objectives

- Gain practical experience with SOC operations
- Understand SIEM architecture and log management
- Simulate attacker techniques in a controlled environment
- Monitor Windows endpoints for suspicious activity
- Investigate alerts and validate detections
- Build a portfolio demonstrating practical cybersecurity skills

## 🏗️ Lab Overview

The lab consists of a dedicated Wazuh server and monitored Windows endpoint(s), creating a realistic environment for security monitoring and threat detection.

The project covers the complete lifecycle of:

- Environment setup
- Endpoint onboarding
- Event collection
- Threat detection
- Alert analysis
- Investigation
- Documentation
